# Required input workbooks

This folder is intentionally free of real workbooks. Add local files that
match the paths in `../config.json`:

- `source_workbook.xlsx`: source rows and the configured source worksheet.
- `mapping_workbook.xlsx`: mapping values and the configured mapping worksheet.

The example configuration uses the worksheet names `SourceData` and `Mapping`.
Change them when your workbooks use different names.

Do not commit confidential or personal data to this example folder. Use a
separate local copy or an ignored data directory for real inputs.
