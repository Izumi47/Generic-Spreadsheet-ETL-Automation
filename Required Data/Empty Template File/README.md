# Template placeholders

Add the configured template workbooks to this folder. The example names are:

- `01_Record_Addition.xlsx`
- `02_Allocation_Addition.xlsx`
- `03_Charge_Addition.xlsx`
- `04_Ledger_Addition.xlsx`

Each workbook must contain the worksheet name configured for its step. The
allocation workbook must also contain the configured lookup worksheet. These
files are templates, not generated outputs; keep their headers and formatting
under change control.
